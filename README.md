# 39 donuts — Astro + JavaScript

Статический лендинг с готовым HTML, адаптивным оформлением и четырёхшаговой анкетой. React и Next.js в этой реализации не используются. Сборку выполняет Astro; Vite работает внутри него.

## Запуск

Рекомендуемая версия Node указана в [.nvmrc](.nvmrc), зависимости зафиксированы в [package-lock.json](package-lock.json).

```sh
nvm use
npm ci
npm run dev -- --port 4324
```

Главная: `http://127.0.0.1:4324/`. Политика: `http://127.0.0.1:4324/privacy-policy/`.

## Основные команды

| Команда                                     | Результат                                                                         |
| ------------------------------------------- | --------------------------------------------------------------------------------- |
| `npm run dev -- --port 4324`                | Разработка с обновлением страницы при правках                                     |
| `npm run format`                            | Форматирование кода и документации                                                |
| `npm run check`                             | Форматирование, ESLint, тесты, production-сборка, HTML, SEO и ссылки документации |
| `npm run check:preview`                     | Preview-сборка и проверка её SEO-режима                                           |
| `npm run build`                             | Production-файлы в `dist/`                                                        |
| `npm run build:preview`                     | Демонстрационная сборка в `dist-preview/`, страницы с `noindex`                   |
| `npm run preview -- --port 4324`            | Просмотр ранее собранной `dist-preview/`                                          |
| `npm run preview:production -- --port 4324` | Просмотр ранее собранной `dist/`                                                  |
| `npm run release`                           | Все production-проверки и архив с SHA256 в `releases/`                            |
