## Запуск

Рекомендуется Node.js 22.23.0 (указан в `.nvmrc`). Поддерживаются Node.js 22.13+ и 24+.

```sh
nvm use
npm ci
npm run dev -- --port 4321
```

Для предпросмотра готовой сборки:

```sh
npm run build:preview
npm run preview -- --port 4321
```

| Команда | Результат |
| --- | --- |
| `npm run dev` | Разработка; страницы содержат `noindex` |
| `npm run build:preview` | Сборка для сверки в `dist-preview/`, закрытая от индексации |
| `npm run preview` | Локальный сервер для `dist-preview/` |
| `npm run build` | Production-сборка в `dist/` для `https://39donuts.ru/` |
| `npm run preview:production` | Локальный просмотр `dist/` после production-сборки |
| `npm run check` | ESLint, тесты анкеты и SEO, production-сборка и проверки готового HTML |
| `npm run release` | Все проверки и архив `releases/39donuts-production.tar.gz` с SHA256 |

В хостинг загружается содержимое `dist/`, включая скрытый `.htaccess`. Это готовые HTML, CSS, JavaScript и ресурсы: Node.js для обслуживания сайта не нужен. Каталоги сборок не редактируются вручную и не включаются в Git. Для архивации командой `release` нужна установленная утилита `tar`.

## Структура

- `src/pages/` — страницы и их порядок секций.
- `src/layouts/` — общий HTML-документ, метаданные, подключение стилей и скриптов.
- `src/sections/` — самостоятельные блоки лендинга.
- `src/components/` — брендовый текст, SVG-иконки, галерея и телефон.
- `src/features/` — анкета, форматы, FAQ и навигация.
- `src/data/` — тексты, показатели, контакты, варианты ответов, SEO-настройки и политика обработки персональных данных.
- `src/lib/seo.js` — canonical, структурированные данные, sitemap и robots.txt.
- `src/scripts/` — запуск интерактивности, навигация, вкладки, анимации и скроллбар.
- `src/styles/` — сохранённые CSS-слои утверждённого дизайна.
- `public/` — локальные изображения, иконка вкладки, карточка для ссылок и настройки Apache.
- `deploy/` — пример правил Nginx для существующего хостинга.
- `scripts/` — команды сборки, проверка выпуска и упаковка.
- `tests/` — проверки анкеты и SEO.
- `docs/` — устройство проекта, визуальная приёмка, SEO и размещение.

`tsconfig.json` используется инструментами Astro для подсказок редактора; исходники пишутся на JavaScript и Astro.

## SEO и размещение

Production-сборка содержит метаданные, canonical, Open Graph, структурированные данные, `robots.txt`, `sitemap.xml`, страницу политики по прежнему адресу и страницу 404. Главная страница и политика доступны поисковикам как готовый HTML. Предпросмотр содержит `noindex`; режим задаётся командами, поэтому случайное значение `PUBLIC_SITE_MODE` в окружении или `.env` не меняет назначение сборки.

Домен по умолчанию — `https://39donuts.ru/`. Изменение домена задаётся через окружение команды, например `SITE_URL=https://example.ru npm run build`. Разрешён только HTTPS-адрес без подпапки, параметров и якоря. При смене домена также нужно обновить серверные правила. `SITE_URL` из `.env` конфигурация сборки автоматически не читает.

- [Настроенное SEO и места редактирования](docs/SEO.md).
- [Подготовка выпуска и настройки хостинга](docs/DEPLOYMENT.md).

## Отправка заявок

Анкета пока повторяет локальное завершение эталона. Она не отправляет данные. Подключение существующего обработчика Telegram будет сделано после получения исходников компании и проверки его контракта. Секреты обработчика не должны находиться в `public/` или браузерном JavaScript.

Перед полноценным запуском нужно подключить обработчик и проверить получение заявки в Telegram. При загрузке статических файлов необходимо сохранить существующий `/api/` и другие серверные файлы компании.

Сведения о происхождении изображений и шрифтов сохранены в `ASSET_SOURCES.md` и `THIRD_PARTY_NOTICES.md`.
