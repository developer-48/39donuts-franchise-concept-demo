# 39 donuts — Astro + JavaScript

Статический лендинг с готовым HTML, адаптивным оформлением, четырёхшаговой анкетой и отдельной 3D-примерочной форматов кофеен. React и Next.js в этой реализации не используются. Сборку выполняет Astro; Vite работает внутри него.

## Запуск

Рекомендуемая версия Node указана в [.nvmrc](.nvmrc), зависимости зафиксированы в [package-lock.json](package-lock.json).

```sh
nvm use
npm ci
npm run dev -- --port 4324
```

| Адрес                                         | Назначение                              |
| --------------------------------------------- | --------------------------------------- |
| `http://127.0.0.1:4324/`                      | Лендинг с исходными фотографиями        |
| `http://127.0.0.1:4324/lab/formats/#formats`  | Тот же лендинг с утверждённым 3D-блоком |
| `http://127.0.0.1:4324/lab/baseline/#formats` | Фотографический вариант для сравнения   |
| `http://127.0.0.1:4324/lab/`                  | Вход в локальную 3D-примерочную         |

3D подключается только на маршрутах `/lab/`. Добавление или правка модели пока не меняет главную `/`. Примерочная закрыта от индексации, в том числе в production-сборке. Точный состав выпуска описан в [DEPLOYMENT.md](docs/DEPLOYMENT.md).

## Основные команды

| Команда                                     | Результат                                                                         |
| ------------------------------------------- | --------------------------------------------------------------------------------- |
| `npm run dev -- --port 4324`                | Разработка с обновлением страницы при правках                                     |
| `npm run format`                            | Форматирование кода и документации                                                |
| `npm run check`                             | Форматирование, ESLint, тесты, production-сборка, HTML, SEO и ссылки документации |
| `npm run check:preview`                     | Preview-сборка и проверка её SEO-режима                                           |
| `npm run build`                             | Production-файлы в `dist/`                                                        |
| `npm run build:preview`                     | Демонстрационная сборка в `dist-preview/`, страницы с `noindex`                   |
| `npm run preview -- --port 4324`            | Просмотр ранее собранной `dist-preview/`                                          |
| `npm run preview:production -- --port 4324` | Просмотр ранее собранной `dist/`                                                  |
| `npm run release`                           | Все production-проверки и архив с SHA256 в `releases/`                            |
