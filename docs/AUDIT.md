# Аудит исходников и структуры — 24 сентября 2026

## Объём проверки

Проверены состав исходников, зависимости, контентный модуль, форма, ассеты, CSS-слои, сборка Vite, настройки GitHub Pages и опубликованный репозиторий. После аудита удалены промежуточные варианты E/F и демонстрационный предпросмотр анимаций; оставлена одна утверждённая страница. Проверка включает `npm run check` и визуальное сравнение с прежним G на компьютере и телефоне.

## Что сохранено

- адреса главной страницы и `/showcase/`; старые `/e`, `/f`, `/g` перенаправляются на главную;
- порядок секций, контент и внешний вид утверждённого сайта;
- доступность вкладок, FAQ, мобильного меню и диалогов;
- применяемые CSS-правила и порядок их действия, все используемые оригинальные ассеты;
- формат сборки GitHub Pages с `404.html` и `.nojekyll`.

## Результаты повторной проверки

- `npm ci` — установка из lockfile проходит;
- `npm run check` — ESLint, 4/4 теста, TypeScript и сборка проходят;
- `npm audit` — 0 известных уязвимостей на момент проверки;
- после удаления альтернативных веток сборка JavaScript уменьшилась с 304,58 до 286,86 КБ до очистки неиспользуемых стилей;
- полные снимки утверждённой страницы имеют прежнюю высоту на экранах 1440 и 430 px; после завершения анимаций визуальное сравнение показывает сохранение макета.

## Ограничение проверки

Браузерная проверка использует локальный браузер/эмуляцию ширины экрана; она не заменяет испытание на физическом устройстве и не подтверждает права на коммерческое использование изображений.
