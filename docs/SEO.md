# SEO-настройки

Сайт собирается в статический HTML. Заголовки, тексты, форматы и ответы FAQ присутствуют в документе до выполнения JavaScript. SEO-настройки не меняют визуальную структуру главной страницы.

## Домен и индексация

Основной адрес — `https://39donuts.ru/`. Production-сборка выпускается командой `npm run build` в `dist/`. Главная страница и `/privacy-policy/` содержат `index, follow` и canonical на собственный адрес.

`npm run dev` и `npm run build:preview` выпускают страницы с `noindex, nofollow`. `robots.txt` допускает чтение страниц, чтобы поисковики могли увидеть директиву `noindex`; карта предпросмотра не содержит URL. Публичную демонстрацию следует размещать из `dist-preview/`, а официальный сайт — из `dist/`.

Режим принудительно выбирается npm-командой через `scripts/astro-command.mjs`. Менять `PUBLIC_SITE_MODE` в `.env` для публикации не нужно.

## Что подготовлено

| Часть | Реализация |
| --- | --- |
| Заголовки и описание | Отдельные title и description главной, политики и страницы 404; язык документа `ru` |
| Canonical | Абсолютные HTTPS-адреса без параметров и якорей; у 404 canonical отсутствует |
| Карточка ссылки | Open Graph и Twitter Card; изображение `/og/39donuts-franchise.png`, 1200 × 630 |
| Данные компании | JSON-LD: Organization, WebSite, WebPage; контакты и юридические данные сверены с действующим сайтом |
| FAQ | FAQPage с вопросами и ответами из тех же данных, что отображаются на странице |
| Карта сайта | `/sitemap.xml`: только `/` и `/privacy-policy/`, без выдуманной даты изменения |
| Robots | `/robots.txt` допускает индексацию production-версии и указывает её sitemap |
| Политика | Текст опубликованной политики перенесён на прежний путь `/privacy-policy/`; исходная редакция от 28 мая 2026 года |
| Ошибки | Статическая `/404.html` с `noindex`; HTTP-код 404 обеспечивают настройки хостинга |
| Изображения | Размеры в HTML, ленивое чтение изображений ниже первого экрана; основное изображение первого экрана загружается приоритетно |
| Старые ссылки | Правила для `/e`, `/f`, `/g` и соответствие прежних якорей текущим секциям |

Изображения и шрифты главной сохранены. Не добавлены аналитика, сторонние трекеры, фиктивные рейтинги, обещания доходности или разметка отдельной кофейни вместо сети. FAQPage описывает содержание сайта; наличие этой разметки само по себе не означает выдачу специального блока в поиске.

## Что редактировать

| Файл | Назначение |
| --- | --- |
| `src/data/seoContent.js` | Домен по умолчанию, название, title/description главной, изображение для ссылок, список индексируемых страниц |
| `src/data/siteContent.js` | Контакты, юридические данные, текст FAQ и основное содержание |
| `src/data/privacyContent.js` | Опубликованный текст политики |
| `src/layouts/BaseLayout.astro` | Общие метатеги и подключение JSON-LD |
| `src/lib/seo.js` | Формирование URL, JSON-LD, sitemap и robots.txt |
| `src/pages/privacy-policy.astro` | Метаданные и оформление политики |
| `public/og/39donuts-franchise.png` | Карточка для ссылок в мессенджерах и соцсетях |

Контакты и FAQ в разметке берутся из общих данных, поэтому их не нужно дублировать вручную в метатегах. При добавлении отдельной страницы нужно задать её title/description и включить canonical-путь в `indexablePaths`, если страницу следует индексировать.

Для другого официального домена:

```sh
SITE_URL=https://example.ru npm run release
```

Домен должен быть HTTPS origin без подпапки, параметров и якоря. Значение передаётся окружением команды; `.env` конфигурация Astro автоматически не читает. Вместе с ним меняются canonical, sitemap, ссылки JSON-LD и карточки. Правила Apache/Nginx для `39donuts.ru` при этом нужно изменить отдельно.

## Прежние адреса

В комплекте есть правила серверных 301-переходов `/e`, `/f`, `/g` на `/`, а также `/index.html` на `/`. Для официального домена необходимо привести HTTP и www к `https://39donuts.ru/`. Проверка действующего сайта показала отдельные доступные HTTP/www-версии и отсутствие canonical, robots.txt и sitemap; настройки новой сборки должны применяться вместе с серверными правилами.

Старые якорные ссылки сохраняют смысл:

| Прежний якорь | Текущий якорь |
| --- | --- |
| `#hero` | `#top` |
| `#about` | `#story` |
| `#coffee-shops` | `#network` |
| `#shop-formats` | `#formats` |
| `#partners` | `#application` |

Якоря переводятся браузерным JavaScript: часть URL после `#` не отправляется серверу. Секции не являются отдельными страницами и не перечисляются в sitemap.

## Проверка и действия после размещения

`npm run check` проверяет исходники, тесты, статический HTML, метаданные, sitemap, robots, ссылки на локальные ресурсы и размер карточки. Порядок размещения и проверки HTTP-ответов описан в [DEPLOYMENT.md](DEPLOYMENT.md).

После загрузки на официальный домен владелец подтверждает доступ в Google Search Console и Яндекс Вебмастере, затем передаёт `https://39donuts.ru/sitemap.xml` и проверяет главную и политику инструментами проверки URL. Идентификаторы подтверждения пока не предоставлены; выдуманные теги в код не добавлены. Если подтверждение требует HTML-тега или файла, его можно добавить после получения данных владельца.

Исходная политика не описывает добавленную аналитику: трекеры сейчас не подключены. Если позже меняются обработка заявок, CRM или аналитика, текст политики должен соответствовать фактической реализации.
