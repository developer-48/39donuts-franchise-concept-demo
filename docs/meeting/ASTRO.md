# Astro: что это и как объяснить выбор на встрече

Материал для Юсупа к встрече 26 октября 2026. Основная инструкция по файлам проекта находится отдельно.

## Короткий ответ

**Astro — фреймворк для создания сайтов, который умеет заранее собирать страницы в готовый HTML.** Разработчик работает с компонентами и данными, а посетитель получает обычную веб-страницу. Для нашего лендинга выбран именно статический режим. Astro также умеет работать с серверным рендерингом, но он сейчас не используется. Это соответствует описанию [Astro-компонентов](https://docs.astro.build/en/basics/astro-components/) в официальной документации.

## Как устроен наш сайт

```text
Компоненты + тексты + CSS + JavaScript
                  ↓ сборка Astro
        Готовые HTML, CSS, JS и ресурсы
                  ↓ хостинг
               Браузер
```

- **HTML** содержит заголовки, тексты, показатели форматов и вопросы.
- **CSS** отвечает за дизайн, фирменные цвета и мобильную версию.
- **JavaScript** добавляет меню, переключения, анкету и анимации.
- **Astro** собирает эти части в страницы; **Vite** внутри него обрабатывает модули и ресурсы.

Компонент — отдельный блок с понятной ответственностью: например, шапка, FAQ или кнопка. Его можно менять без копирования всей страницы. При этом обычный Astro-компонент не требует отдельного React runtime в браузере. Возможность добавлять интерактивность описана в [документации компонентов](https://docs.astro.build/en/basics/astro-components/).

## Почему этот подход выбран для 39 donuts

Это лендинг франшизы: основной объём — содержание, фотографии, условия и путь к заявке. Ему нужны готовый HTML, адаптивность и несколько интерактивных сценариев. На этом основании для нашего проекта выбран Astro со статической сборкой и обычным JavaScript.

Практический результат:

1. Поисковик получает содержание в исходном HTML и не должен ждать выполнения приложения, чтобы увидеть основные тексты.
2. Хостинг отдаёт уже подготовленные файлы; для этих страниц не нужен постоянно работающий Node-сервер.
3. Код разделён по секциям: тексты, стили и поведение имеют понятные места.
4. Мы контролируем, какой JavaScript добавляем. Это помогает ограничивать нагрузку, хотя само название фреймворка скорость не гарантирует.

Astro ориентирован на сайты с большим объёмом содержания; это описано в [обосновании подхода](https://docs.astro.build/en/concepts/why-astro/). Выбор именно для нашего лендинга — техническое решение на основе его задач.

## Что связано с SEO

На нашей стороне подготовлены заголовки и описания страниц, canonical, изображение для ссылок, структурированные данные JSON-LD, sitemap, robots и настоящая страница 404. Основное содержание находится в готовом HTML.

Это **техническая SEO-подготовка**. Для продвижения также нужны актуальное содержание, подходящие запросы, проверка индексации и дальнейшая работа. Обещать топ поиска только за выбор Astro нельзя.

Говорить, что React вообще не подходит для SEO, тоже некорректно: результат зависит от способа рендеринга, React можно [предварительно рендерить в HTML](https://react.dev/reference/react-dom/static/prerender). В нашем случае Astro позволяет решить задачу готового HTML без необходимости вводить React.

## Что ответить на частые вопросы

**«Это конструктор?»**

Нет, это разработка с собственными компонентами, стилями и логикой. Админки для редактирования из браузера сейчас нет; для неё потребуется отдельное подключение CMS.

**«Можно потом менять сайт?»**

Да. Тексты и показатели хранятся в файлах данных и компонентах, цвета — в общих CSS-переменных. После правок сайт пересобирается и загружается на хостинг.

**«Нужен особый хостинг?»**

Для статических страниц достаточно отдачи HTML, CSS и JavaScript. Совместимость действующего обработчика заявок и серверных правил проверяется отдельно. Статический и серверный способы размещения различаются; см. [руководство Astro по размещению](https://docs.astro.build/en/guides/deploy/).

**«Почему JavaScript, а не TypeScript?»**

В проекте ограниченная клиентская логика, она проверяется линтером и тестами. Использование JavaScript — осознанный выбор; возможность добавить TypeScript позднее остаётся.

## Как сказать директору за полминуты

Для лендинга это позволяет обойтись обычным статическим хостингом и сохранить понятный код по блокам. Подготовлены адаптивный дизайн, анимации и техническая SEO-разметка. Перед официальным запуском нужно подключить ваш обработчик заявок и проверить сайт на вашем домене.
