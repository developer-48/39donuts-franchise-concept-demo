# Устройство Astro-версии

`src/pages/index.astro` собирает девять секций, шапку, подвал и анкету. `BaseLayout.astro` выпускает полный HTML-документ. Основные тексты, показатели, все форматы и вопросы присутствуют в HTML после сборки; клиентскому JavaScript не требуется создавать страницу.

## Разметка и данные

Крупные секции живут в `src/sections/`. Форматы и FAQ в `src/features/` заранее выводят все данные в HTML, а `tabs.js` управляет видимостью, ARIA-состояниями и клавиатурой. Тексты и пути к изображениям находятся в `src/data/siteContent.js`. Названия и варианты ответов анкеты — в `applicationContent.js`.

## Анкета

`ApplicationWizardDialog.astro` содержит разметку четырёх шагов; небольшие компоненты отвечают за поля, группы переключателей и текстовые области. `controller.js` управляет переходами, фокусом, блокировкой фона и локальным завершением. `model.js` проверяет значения; `review.js` выводит заполненные ответы через DOM API и `textContent`. Необязательные пустые поля и группы не выводятся, контакт не дублируется.

Все поля сохраняются в DOM при смене шага. При новом открытии значения сбрасываются, как в эталоне. Высота окна и доступная прокрутка задаются сохранёнными CSS-правилами. Будущая отправка будет подключена к серверному API после отдельной проверки существующего обработчика компании.

## Стили и поведение

`src/styles/index.css` фиксирует порядок загрузки шрифтов и пяти CSS-слоёв: `global`, `site-foundation`, `site-refinements`, `site-interactions`, `donut-scrollbar`. Порядок имеет значение для адаптивного дизайна. `astro-runtime.css` только обеспечивает скрытие неактивных HTML-панелей.

`site.js` запускает модули один раз. `navigation.js` управляет меню и переходами к секциям; `motion.js` повторяет однократные анимации по IntersectionObserver и reduced motion. `donut-scrollbar.js` работает только на широких экранах с точным указателем; при недоступном изображении остаётся стандартный scrollbar.

## Сборка и размещение

`npm run build` выпускает статический каталог `dist/`. Его можно отдавать через Nginx, Apache или статический хостинг. Исходный репозиторий хранит компоненты, данные, стили, зависимости и документацию; в хостинг загружается результат сборки. Для воспроизводимости версия Node ограничена в `package.json`, зависимости фиксируются `package-lock.json`.
