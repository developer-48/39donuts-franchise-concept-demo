# Устройство проекта

## Страница и композиция

`src/App.tsx` собирает единственную утверждённую страницу из девяти секций и управляет открытием анкеты. Общие данные находятся в `src/data/siteContent.ts`. В `src/main.tsx` старые адреса `/e`, `/f`, `/g` перенаправляются на корень с учётом Vite `BASE_URL`.

Секции из `src/sections/` отвечают за разметку крупных блоков страницы. Интерактивные подсистемы находятся в `src/features/`: анкета, FAQ, форматы, навигация. Переиспользуемые визуальные элементы остаются в `src/components/`.

## Стили

`src/main.tsx` загружает слои строго в таком порядке:

1. `global.css` — токены, общие компоненты и адаптивная база;
2. `site-foundation.css` — базовая композиция секций;
3. `site-refinements.css` — уточнения сеток и адаптивности;
4. `site-interactions.css` — интерактивные состояния и анимации;
5. `donut-scrollbar.css` — отдельный скроллбар для компьютера.

Все слои применяются к одной странице с корневым классом `.site`. Порядок правил сохранён из утверждённого макета; переносить правила между файлами следует с визуальной проверкой на компьютере и телефоне.

## Данные и ассеты

`siteContent.ts` — единый перечень текстов, цифр, контактов и путей к изображениям. `public/assets/official/` хранит локальные копии изображений исходного сайта; `public/assets/concept/` — специально созданные элементы концепта; `public/assets/icons/` — SVG-пиктограммы. Имена оригинальных файлов сохранены, а понятные алиасы даны в объекте `assets`. Сведения о происхождении — в корневом `ASSET_SOURCES.md`.

`public/showcase/` — отдельный презентационный макет утверждённого сайта. Он автоматически копируется Vite в `dist/`.

## Сборка и публикация

Ветка `source` хранит код, документацию и статические исходные ресурсы. Ветка `main` содержит только содержимое `dist/`, откуда GitHub Pages публикует сайт. Публикация вручную: выполнить `npm ci`, `npm run check`, `npm run build:pages`, проверить готовую сборку, затем перенести содержимое `dist/` в `main` отдельным коммитом. Нельзя синхронизировать непроверенную локальную папку проекта целиком с `main`.

`prepare-pages.mjs` создаёт `404.html` как копию `index.html` для старых адресов и переходов с фрагментами на GitHub Pages. Базовый путь задаётся в `build:pages`.

## Анкета

Четырёхшаговая анкета хранит состояние в React, без `fetch`, XHR, local/session storage и серверного `action`. Надпись «Отправить заявку» завершает локальный сценарий; серверного приёма заявок в концепте нет. Для реального сайта это отдельная задача с API, обработкой ошибок и юридической проверкой.
