# Перенос с сохранением утверждённого визуала

Этот документ описывает первоначальный перенос с React/Vite на Astro. Перенос завершён; после него исходники упорядочены по компонентам 12 октября 2026. Текущая структура — в [ARCHITECTURE.md](ARCHITECTURE.md), инструкция по правкам — в [EDITING.md](EDITING.md), результаты обеих проверок — в [AUDIT.md](AUDIT.md).

Эталон: ветка `source`, коммит `942475f63ebfc1019af6d3b5392989ea46cbe80e`.

## Волны

1. Отдельный worktree и ветка Astro от эталона.
2. Перенос HTML, данных, ресурсов, интерактивности и анимаций на Astro + JavaScript.
3. Независимая проверка сценариев и сравнение геометрии/скриншотов на адаптивном диапазоне.
4. Исправление расхождений, проверка статической сборки и документация результата.

## Условия приёмки

- Эталонная ветка и каталог не изменяются.
- Содержание и визуальные решения остаются прежними, включая числовые показатели, брендовый шрифт и цвета.
- Форматы, FAQ, меню, все шаги анкеты и однократные анимации воспроизводят эталон.
- В десктопной анкете размер окна стабилен, длинное содержимое прокручивается; на телефоне кнопки доступны.
- Клавиатура, Escape, возврат фокуса и reduced motion работают.
- Готовый HTML содержит содержание сайта; никакого React runtime для страницы нет.
- Telegram и официальная публикация выполняются после получения источников/доступов и согласования визуала.
