# Документация проекта

Документы относятся к актуальной Astro-реализации в ветке `design/3d-motion-lab`. Инструкция по основному лендингу отделена от материалов к встрече и экспериментальных доработок.

| Документ                               | Что в нём                                                                    |

| [Краткая инструкция](PROJECT_GUIDE.md) | Подход, запуск, карта папок, обычные правки, анкета, SEO и выпуск            |
| [Повседневные правки](EDITING.md)      | Цвет, кнопка, FAQ, картинка, поле анкеты                                     |

| [Размещение](DEPLOYMENT.md)            | Состав сборки, архив, Apache/Nginx, сохранение API и проверка после загрузки |
